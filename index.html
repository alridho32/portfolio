Agentic reporting · Runs monthly

B2B Active & New Partner Report (MAU / NPU)

One prompt ("generate MAU NPU for May 2026") makes the agent query four reporting sources plus the data warehouse, apply the business rules, and deliver a formatted two-sheet Excel report. It replaces a manual pivot-and-copy process across several dashboards.

  1. ParseMonth → date range
  2. Fetch4 BI views via MCP + warehouse SQL
  3. RulesStatus filters, case-insensitive dedup, first-ever transaction
  4. Build2-sheet Excel (openpyxl), styled sections
Built with: Claude Agent Skill · MCP (Metabase) · ClickHouse SQL · Python · openpyxl

New-partner logic · warehouse SQL
-- partners whose FIRST-EVER transaction
-- falls inside the requested month
SELECT
  argMin(partner_name, completed_at) AS company,
  partner_id,
  argMin(product, completed_at) AS first_product,
  min(completed_at)              AS first_trx_at
FROM dwh.payables_history
GROUP BY partner_id
HAVING min(completed_at) >= '{start}'
   AND min(completed_at) <  '{end}'

Agentic reporting · Runs monthly

Monthly Remittance KPI Report

The agent asks for the month, pulls eight KPIs for a remittance corridor in a single aggregated query (no raw-row dumps), shows the summary in chat, and exports a formatted Excel with correct currency formats.

  1. AskWhich month & year?
  2. AggregateOne SQL over the reporting view via MCP
  3. ReviewKPI table in chat (SGD / IDR)
  4. ExportExcel summary with number formats
Built with: Claude Agent Skill · MCP (Metabase) · SQL · Excel
View evidence (anonymized)
Aggregation query
SELECT
  COUNT(*)                  AS trx,
  SUM(gtv_local)            AS gtv,
  SUM(initial_fee)          AS fee,
  SUM(fx_margin_revenue)    AS fx_rev,
  SUM(fx_margin_cost)       AS fx_cost,
  SUM(discount)             AS promo_cost,
  COUNT(DISTINCT sender_id) AS mau,
  SUM(is_first_trx)         AS npu
FROM reporting_view
WHERE status = 'completed'
  AND completed_at >= '{start}'
  AND completed_at <  '{next_month}'

04
Framework · Reusable

Automation Creator: Reusable Python Automation Framework

A skill that turns a business question into a complete, scheduled Python automation. It starts by defining who reads the output and which 3–5 questions it must answer, agrees on the report layout, then generates the pipeline: an MCP client with auth and retry, pandas transforms, narrative insights written in plain language, Excel export, and a daemon/cron mode.

  1. Use caseReader, decision, 3–5 questions
  2. NarrativeAgree report sketch before coding
  3. Pipelinefetch → transform → insights → export
  4. ShipCLI + scheduled runs, env-based config
Built with: Python · MCP JSON-RPC · Pandas · Logging & retry · Cron / daemon
